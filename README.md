# منوی دیجیتال کافه (digital-menu)

سیستمِ منوی دیجیتال و سفارش‌گیریِ کافه:

- **رابطِ مشتری و کارکنان** با **React + shadcn/ui + Tailwind + TypeScript** (پوشهٔ `web/`).
- **بک‌اند** با **Node.js + Express + Socket.IO** و ذخیره‌سازیِ فایلی (پوشهٔ `server/`).
- یک سرور، یک پورت: بک‌اند هم API می‌دهد و هم خروجیِ بیلدِ React را سرو می‌کند.

## امکانات

**مشتری** (`/?table=۱`)
- سه حالتِ نمایش منو: کاروسل سه‌بعدی / شبکه‌ای / لیستی، به‌همراه دارک‌مود و چیدمانِ راست‌به‌چپ.
- برندینگِ کافه (نام/لوگو/شعار) از تنظیمات خوانده می‌شود.
- ثبتِ سفارش، **صورتحساب = جمعِ همهٔ سفارش‌های پرداخت‌نشدهٔ میز** + نمایشِ تک‌تکِ فاکتورها.
- **نمایشِ اطلاعاتِ پرداخت** (شماره کارت/به‌نام/لینک) روی صورتحساب + ارسالِ رسید (مهرِ ضدجعل سمتِ سرور).
- **وضعیت سفارشِ لحظه‌ای** (Socket.IO) بدون رفرش.
- دکمهٔ درخواست: صدا زدنِ گارسون / درخواستِ فاکتور.
- **ثبت نظر و امتیاز** (نظرسنجی).

**کارکنان** (`/staff` — رمزِ پیش‌فرض `cafe1234`)
- **سفارش‌ها**: کنترلِ آشپزخانه (تأیید→آماده‌سازی→آماده→سرو) + صندوق (دیدن فیش، تأیید/رد با حذفِ عکس، هشدارِ فیشِ تکراری).
- **درخواست‌ها**: تبِ جدا برای گارسون/فاکتور با مبلغِ صورتحساب.
- **نظرسنجی**: نظر و امتیازِ مشتری‌ها (زنده) با میانگین.
- **مشتری‌ها**: بانکِ شماره‌ها با تعداد مراجعه + خروجی **CSV**.
- **مدیریت منو**: افزودن/ویرایش/حذفِ محصول و دسته (ایموجی یا آپلودِ عکس) + تولیدِ **QR** میزها با چاپ.
- **تنظیمات**: نام/لوگو/شعارِ کافه، واحد پول (تومان/ریال)، **اطلاعاتِ پرداخت (کارت‌به‌کارت)**، تغییرِ رمز، و تنظیماتِ پیشرفتهٔ پیامک و درگاه‌ها.
- همه‌چیز زنده به‌روزرسانی می‌شود.

## اجرا روی سیستم خودت (توسعه)

```bash
npm run setup     # نصب بک‌اند + نصب و بیلدِ web/
npm start         # http://localhost:3000
#   مشتری:   http://localhost:3000/?table=1
#   کارکنان: http://localhost:3000/staff   (رمز: cafe1234)
```

برای توسعهٔ رابط با هات‌ری‌لود، در ترمینال دوم: `cd web && npm run dev` (پراکسی به بک‌اند تنظیم شده).

## نصب روی سرور اوبونتو (دائمی، با دامنه و SSL)

از داخلِ پوشهٔ ریپو، اسکریپتِ نصب را با sudo اجرا کن:

```bash
sudo DOMAIN=example.com EMAIL=you@example.com ADMIN_PASSWORD='یک-رمز-قوی' bash install.sh
```

این اسکریپت: Node 20 را نصب می‌کند، وابستگی‌ها را نصب و `web/` را بیلد می‌کند، سرویسِ **systemd**
می‌سازد (اجرای دائمی + استارت بعد از ری‌بوت)، **Nginx** را به‌عنوان reverse proxy تنظیم می‌کند،
و در صورت دادنِ `DOMAIN` و `EMAIL`، گواهیِ **SSL** رایگان (Let's Encrypt) می‌گیرد.

> قبلش مطمئن شو رکوردِ DNSِ دامنه به IP سرور اشاره می‌کند و پورت‌های ۸۰ و ۴۴۳ باز است.

مدیریتِ سرویس:
```bash
systemctl status cafe          # وضعیت
journalctl -u cafe -f          # لاگ زنده
systemctl restart cafe         # ری‌استارت
```

## به‌روزرسانی

```bash
git pull
npm run build:web && sudo systemctl restart cafe
```

## ساختار

```
server/        بک‌اند Node/Express/Socket.IO (API، صورتحساب، واترمارک، احراز هویت)
web/           رابط React (مشتری + کارکنان + مدیریت)
data/          دادهٔ اولیهٔ منو (menu.json)؛ سفارش‌ها/تنظیماتِ زمان‌اجرا اینجا ساخته می‌شوند
public/        product.html (پیش‌نمایشِ اشتراک‌گذاری) و public/images (آپلودها)
install.sh     نصبِ سرورِ اوبونتو (systemd + nginx + ssl)
```

داده‌ها به‌صورت فایلی در `data/` و تصاویر در `public/images/` ذخیره می‌شوند؛ برای بکاپ، همین دو را نگه دار.
