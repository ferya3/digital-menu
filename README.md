# منوی دیجیتال کافه (digital-menu)

منوی دیجیتال و سفارش‌گیریِ کافه — **Node.js + Express + Socket.IO** با پنل‌های کامل مدیریت.

## امکانات

**مشتری** (`/?table=۱`): منوی دسته‌بندی‌شده، سبد خرید، ثبت سفارش، **صورتحساب = جمعِ همهٔ سفارش‌های پرداخت‌نشدهٔ میز**، ارسال رسید پرداخت، وضعیت سفارشِ لحظه‌ای، درخواست گارسون/فاکتور، و نظرسنجی.

**مدیریت** (`/login` → داشبورد `/manager`): سفارش‌ها، صندوق (تأیید/رد فیش با واترمارک)، درخواست‌ها، آشپزخانه، مدیریت منو و دسته‌ها، مشتری‌ها، نظرسنجی، تولید QR میزها، چاپ، و تنظیمات (نام/لوگو، واحد پول، اطلاعات پرداخت، پیامک، درگاه‌ها، رمز).

## اجرا روی سیستم خودت

```bash
npm install
npm start        # http://localhost:3000
#   مشتری: http://localhost:3000/?table=1
#   مدیر:  http://localhost:3000/login   (رمز پیش‌فرض: cafe1234)
```

## نصب روی سرور اوبونتو (دائمی + دامنه + SSL)

```bash
sudo DOMAIN=example.com EMAIL=you@example.com ADMIN_PASSWORD='یک-رمز-قوی' bash install.sh
```
Node، سرویسِ systemd (اجرای دائمی + استارت بعد از ری‌بوت)، Nginx و SSL رایگان را تنظیم می‌کند.
> رکوردِ DNSِ دامنه باید به IP سرور باشد و پورت‌های ۸۰/۴۴۳ باز.

## به‌روزرسانی (بدون از دست رفتن داده)

```bash
sudo bash update.sh
```

## مدیریت سرویس
```bash
systemctl status cafe      # وضعیت
journalctl -u cafe -f      # لاگ زنده
systemctl restart cafe     # ری‌استارت
```

داده‌ها در `data/` (منو، تنظیمات، سفارش‌ها) و عکس‌ها در `public/images/` ذخیره می‌شوند.
